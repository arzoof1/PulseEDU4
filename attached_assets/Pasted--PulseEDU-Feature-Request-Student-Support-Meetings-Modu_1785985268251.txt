# PulseEDU Feature Request: Student Support Meetings Module

## Objective

Design and build a new **Student Support Meetings** module within PulseEDU that centralizes the scheduling, communication, attendance tracking, and documentation for all student support meetings.

This module should replace the current process of emailing teachers and manually collecting feedback by providing an integrated workflow inside PulseEDU.

The architecture should be scalable so the same module can support:

* 504 Meetings
* IEP Meetings
* MTSS Problem-Solving Meetings
* Eligibility Meetings
* Reevaluation Meetings
* Parent Conferences
* Manifestation Determination Meetings
* Other district-defined meeting types

The module should be flexible enough that additional meeting types can be added in the future without requiring database redesign.

---

# Global Navigation

Add a **Meetings** icon (calendar) to the global header navigation.

The icon should display a notification badge whenever the logged-in user has:

* Upcoming meetings
* Pending attendance confirmations
* Required teacher feedback
* Meeting updates

Example:

📅 Meetings (3)

Selecting the icon should open the user's meeting dashboard.

### ESE Case Manager

Can:

* Schedule and manage IEP-related meetings
* View responses
* Edit assigned meetings

---

### MTSS Coordinator

Can:

* Schedule MTSS meetings
* View responses
* Manage MTSS meeting templates

---

### Principal / Assistant Principal

Full administrative access.

Can:

* View all meetings
* Edit meetings
* Monitor participation
* View reporting dashboards

---

### Teachers

Can:

* View assigned meetings
* Confirm attendance
* Decline attendance
* Submit required feedback
* View meeting details
